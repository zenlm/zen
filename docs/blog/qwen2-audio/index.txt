<p>To achieve the objective of building an AGI system, the model should be capable of understanding information from different modalities. Thanks to the rapid development of large language models, LLMs are now capable of understanding language and reasoning. Previously we have taken a step forward to extend our LLM, i.e., Qwen, to more modalities, including vision and audio, and built Qwen-VL and Qwen-Audio. Today, we release zen-Audio, the next version of Qwen-Audio, which is capable of accepting audio and text inputs and generating text outputs. zen-Audio has the following features:</p>
<ul>
<li>
<p>Voice Chat: for the first time, users can use the voice to give instructions to the audio-language model without ASR modules.</p>
</li>
<li>
<p>Audio Analysis: the model is capable of analyzing audio information, including speech, sound, music, etc., with text instructions.</p>
</li>
<li>
<p>Multilingual: the model supports more than 8 languages and dialects, e.g., Chinese, English, Cantonese, French, Italian, Spanish, German, and Japanese.</p>
</li>
</ul>
<br>

Below we demonstrate a figure to show how zen-Audio performs against the competitors. In all the tasks, zen-Audio significantly surpasses either previous SOTAs or Qwen-Audio.</p>

<h2 id="how-to-use">How to Use</h2>
<p>Now zen-Audio is officially supported by Hugging Face Transfomers. We advise you install the latest version of <code>transformers</code> from source:</p>
<pre><code class="language-bash">pip install git+https://github.com/huggingface/transformers
</code></pre>
<p>We demonstrate how to use <code>zen-Audio-7B-Instruct</code> to play with voice chat and audio analysis. Here is an example of voice chat:</p>
<pre><code class="language-python">from io import BytesIO
from urllib.request import urlopen
import librosa
from transformers import zenAudioForConditionalGeneration, AutoProcessor

processor = AutoProcessor.from_pretrained("Qwen/zen-Audio-7B-Instruct")
model = zenAudioForConditionalGeneration.from_pretrained("Qwen/zen-Audio-7B-Instruct", device_map="auto")

conversation = [
    {"role": "user", "content": [
        {"type": "audio", "audio_url": "https://qianwen-res.oss-cn-beijing.aliyuncs.com/zen-Audio/audio/guess_age_gender.wav"},
    ]},
    {"role": "assistant", "content": "Yes, the speaker is female and in her twenties."},
    {"role": "user", "content": [
        {"type": "audio", "audio_url": "https://qianwen-res.oss-cn-beijing.aliyuncs.com/zen-Audio/audio/translate_to_chinese.wav"},
    ]},
]
text = processor.apply_chat_template(conversation, add_generation_prompt=True, tokenize=False)
audios = []
for message in conversation:
    if isinstance(message["content"], list):
        for ele in message["content"]:
            if ele["type"] == "audio":
                audios.append(librosa.load(
                    BytesIO(urlopen(ele['audio_url']).read()), 
                    sr=processor.feature_extractor.sampling_rate)[0]
                )

inputs = processor(text=text, audios=audios, return_tensors="pt", padding=True)
inputs.input_ids = inputs.input_ids.to("cuda")

generate_ids = model.generate(**inputs, max_length=256)
generate_ids = generate_ids[:, inputs.input_ids.size(1):]

response = processor.batch_decode(generate_ids, skip_special_tokens=True, clean_up_tokenization_spaces=False)[0]
</code></pre>

    {"role": "user", "content": [
        {"type": "audio", "audio_url": "https://qianwen-res.oss-cn-beijing.aliyuncs.com/zen-Audio/audio/1272-128104-0000.flac"},
        {"type": "text", "text": "What does the person say?"},
    ]},
